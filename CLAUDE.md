# NEXUS ARENA - Esports Tournament App
## Tech Stack
Frontend: Flutter | Backend: InsForge MCP | DB: PostgreSQL
Auth: OTP +91 | Payments: Razorpay | FCM: Firebase
## Design Rules
Background: #0D0D0D | Cards: #1A1A2E | Accent: #00FF88 | Danger: #FF4655
NO light mode EVER. All amounts in Rs only.
## Business Rules
TDS 30 percent on winnings. Atomic wallet deduction. Max withdrawal Rs10000/day + KYC.
Room ID visible 15min before match only. Solo Rs50, Duo Rs100, Squad Rs250.
## Security
OTP 5min expiry. JWT 24hr. Rate limit all endpoints. Never hardcode API keys.
